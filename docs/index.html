Clips Uploader is a private, internal tool run by one person. It uploads short videos the owner has made to social media accounts the owner controls (YouTube channels, Instagram accounts and TikTok accounts). It is not offered to the public and has no other users.

Clips Uploader uses YouTube API Services. By using Clips Uploader you agree to be bound by the YouTube Terms of Service.

Privacy policy

Last updated 22 October 2026

What the tool accesses

  • YouTube (via YouTube API Services): the basic details of the signed-in channel (channel ID, title and handle) and the ability to upload videos to that channel and read back the uploaded video's status. Scopes used: youtube.upload and youtube.readonly.
  • Instagram (via the Instagram API): the ID and username of the owner's Instagram professional accounts, and the ability to publish Reels to them.
  • TikTok (via the TikTok Content Posting API): the account's open ID and the ability to send a video draft to the account's inbox.

How the data is used

Data is used only to upload the owner's own videos to the owner's own accounts, to check that each upload succeeded, and to keep a log of what was posted (video ID, link and time). It is not used for advertising, profiling or any other purpose.

How the data is stored

Sign-in tokens are stored encrypted in the owner's private cloud storage. The upload log contains only video IDs, links, titles and timestamps. YouTube data obtained through the API is refreshed or deleted within 30 days, in line with the YouTube API Services Developer Policies.

Sharing

No data is sold, rented or shared with any third party. Data passes only between the owner's storage and the platform it is being uploaded to.

Cookies

This website and the tool do not set cookies or use tracking of any kind.

Google's privacy policy

Because the tool uses YouTube API Services, the Google Privacy Policy also applies to data handled by YouTube.

Revoking access and deleting data

  • Google / YouTube: remove Clips Uploader at Google security settings – Third-party apps with account access.
  • Instagram / Facebook: remove it under Settings → Apps and websites, or remove the system user in Meta Business settings.
  • TikTok: remove it under Settings and privacy → Security and permissions → Manage app permissions.

Once access is revoked, the stored tokens stop working. To have all stored tokens and logs deleted, use the contact details below; they are deleted within 7 days.
